# پنل ساخت کانفیگ کلاینت Xray

ابزار وب فارسی و راست‌چین برای ساخت و تبدیل پروفایل‌های کلاینت Xray. ورودی‌های اتصال در مرورگر پردازش می‌شوند و روی سرور یا حساب کاربری ذخیره نمی‌شوند.

## قابلیت‌ها

پنل برای VLESS، VMess، Trojan و Shadowsocks، URI اشتراک و JSON کلاینت Xray می‌سازد. TCP، WebSocket، gRPC، HTTPUpgrade و XHTTP و نیز TLS/Reality در مسیرهای سازگار پشتیبانی می‌شود. URIهای رایج و JSON دارای outbound را می‌توان برای تبدیل وارد کرد. JSON خروجی یک ورودی SOCKS روی `127.0.0.1:10808` و مسیریابی پیش‌فرض به نود دارد. تاریخچه، در صورت درخواست کاربر، فقط در `localStorage` همان مرورگر می‌ماند.

## استقرار Cloudflare

Worker در `cloudflare/worker.js` تعریف شده و با `wrangler.toml` می‌توان آن را استقرار داد:

```sh
npx wrangler login
npx wrangler deploy
```

Worker فایل‌های ثابت را از شاخهٔ `main` همین مخزن عمومی می‌خواند و در Edge با cache کوتاه ارائه می‌کند. این روش به در دسترس بودن `raw.githubusercontent.com` وابسته است؛ ورودی‌ها و اعتبارنامه‌های نود در درخواست به GitHub یا Cloudflare فرستاده نمی‌شوند. برای ساخت bundle مستقل و جاسازی UI در Worker از `npm run build` استفاده کنید؛ خروجی در `dist/worker.js` ایجاد می‌شود.

## حریم خصوصی و محدودیت‌ها

URI و JSON خروجی حاوی اطلاعات اتصال‌اند؛ آن‌ها را مانند رمز عبور نگه دارید. لینک سازنده پروفایل را در URL fragment قرار می‌دهد؛ مرورگر fragment را در HTTP request نمی‌فرستد، ولی هرکس لینک را داشته باشد می‌تواند پروفایل را ببیند. ذخیره محلی اختیاری و محدود به همین دستگاه است.

این پروژه فقط **پروفایل کلاینت** می‌سازد و سرور Xray ایجاد یا اجرا نمی‌کند. برای اتصال واقعی باید یک نود Xray فعال، قابل‌دسترسی و مجاز به استفاده داشته باشید. اعتبارسنجی محلی قالب را بررسی می‌کند، اما همخوانی گزینه‌ها با نسخه و تنظیمات سمت سرور را تضمین نمی‌کند.
