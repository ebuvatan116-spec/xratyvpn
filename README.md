# پنل ساخت کانفیگ کلاینت Xray

یک ابزار وب فارسی و راست‌چین برای ساخت و تبدیل پروفایل‌های کلاینت Xray. ورودی‌های اتصال فقط در مرورگر کاربر پردازش می‌شوند و به‌طور پیش‌فرض روی سرور یا در حسابی ذخیره نمی‌شوند.

## قابلیت‌ها

- ساخت Share URI و فایل کامل JSON کلاینت Xray برای VLESS، VMess، Trojan و Shadowsocks
- پشتیبانی از TCP، WebSocket، gRPC، HTTPUpgrade و XHTTP؛ TLS و Reality برای موارد سازگار
- واردکردن URIها و JSON رایج Xray و تبدیل به فرم قابل‌ویرایش
- خروجی JSON شامل SOCKS محلی روی `127.0.0.1:10808` و مسیریابی پیش‌فرض به outbound پروکسی
- تاریخچه اختیاری در `localStorage` همان مرورگر؛ هیچ همگام‌سازی ابری ندارد
- خروجی اشتراک قابل‌کپی برای Import دستی در کلاینت

## توسعه و استقرار

```sh
npm run build
npx wrangler deploy
```

برای API استقرار مستقیم Cloudflare نیز می‌توان Worker تولیدشده در `dist/worker.js` را آپلود کرد.

## حریم خصوصی و محدودیت‌ها

- URI یا JSON خروجی حاوی اعتبارنامه نود است؛ آن را مانند رمز عبور محافظت کنید.
- ساخت پروفایل به‌تنهایی یک سرور Xray راه‌اندازی نمی‌کند؛ باید نود و پورت/پروتکل سمت سرور از پیش تنظیم و قابل‌دسترسی باشند.
- فرم پیش‌فرض اعتبارسنجی محافظه‌کارانه دارد، اما برای هر نسخه کلاینت/سرور و پروتکل، سازگاری نهایی را با مستندات همان نسخه بررسی کنید.
- این پروژه فقط برای مدیریت نودهایی است که مجاز به استفاده از آن‌ها هستید.
